このサイトについて

「いしかわおでかけ」は、石川県内の今週末のイベント、開催中の展示やフェア、新しくできたお店・スポットをまとめて探せるサイトです。石川の暮らしに役立つ情報を分野ごとのサイトで届ける「ふくふくプロジェクト」のひとつで、Threads「いしかわおでかけ」と連動しています。

  • 運営：ふくふくプロジェクト（Threads「いしかわおでかけ」@ishikawa._ishikawa）
  • 姉妹サイト：ふくいおでかけ（福井県版）

情報の集め方とAIの使い方

  • 主催者・自治体・観光協会・地域メディアなどが公開している情報をもとにしています。各項目に、確かめた出典へのリンクを付けています。
  • 情報の収集と文章の下書きには AI（Anthropic の Claude）を使っています。出典の文章をそのまま写さず、日付・場所・内容を短くまとめています。
  • 運営者が見つけた催しやお店は、出典を確かめたうえで「話題・おすすめ」として手で追加しています。
  • 日付や内容は、集めた時点のものです。中止・変更されることがあるので、お出かけ前に必ず出典（主催者・お店の公式）で確かめてください。
  • 終わった催しは一覧の下にまとめ、最初は表示しないようにしています。

広告（PR）について

  • 「泊まる」の宿の紹介は、楽天トラベルのアフィリエイト（成果報酬型広告）です。リンクから予約されると、運営者に紹介料が入ることがあります。該当する部分には「PR」と表示しています。
  • 宿の情報・写真は楽天トラベルのものです。
  • イベントやお店の掲載で、費用はいただいていません。

プライバシー

  • 表示の設定（選んだタブや地域）は、お使いのブラウザの中にだけ保存します。
  • Instagram の投稿は、「Instagram の投稿を見る」を押したときにだけ Instagram から読み込みます。
  • 楽天トラベルのリンクを押すと、楽天のサイトで Cookie が使われることがあります。

このサイトの情報の利用について

  • このサイトの文章・写真・催しの一覧などを、運営の許可なく複製・転載・再配布・販売することはお断りします。
  • プログラムで自動的に情報を集めること（スクレイピング・クローリングなど）や、AI の学習に使うための収集はお断りします。検索エンジンが検索結果に表示するための収集は除きます。
  • 個々の催しの情報を、私的な利用や引用の範囲で使うことは構いません。その場合は出典として「いしかわおでかけ」を示してください。
